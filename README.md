# Personal Portfolio — Nur E Jannat Asha

Clean, minimalist, responsive personal portfolio website showcasing academic research publications, featured software engineering projects, and tailored CV profiles.

Live Website: [https://jannat332.github.io/portfolio](https://jannat332.github.io/portfolio)

---

## Highlights
- **Zero Framework Bloat**: Built purely with semantic HTML5, modern vanilla CSS, and vanilla JavaScript for sub-100ms load times and high performance.
- **Academic Publications**: Direct links and DOIs to peer-reviewed manuscripts across IEEE and Elsevier journals.
- **Featured Repositories**: Direct links to open-source implementations in C++17, Python, React, Docker, and 5G networking.
- **Integrated CV Downloads**: Direct access to 3 specialized, ATS-compliant CVs (PhD Academic, AI Engineer, Backend Engineer).
- **Responsive & Accessible**: Clean high-contrast typography, mobile-first flex/grid layout, and interactive project category filtering.

